# Pocket Nexus

Pocket Nexus is a modular firmware project for the **M5Stack StickS3**. It turns the StickS3 into a pocket dashboard, utility launcher, and hardware endpoint for personal tools.

## Selected modules

- Pocket Nexus launcher / dashboard
- Stock alert pager
- AI push-to-talk assistant
- Desk information pager
- Calendar next-event view
- RSS / news pager
- IR signal analyzer
- Level / attitude tool
- NTP clock
- Countdown view
- IMU tilt game
- Dice / randomizer
- Wi-Fi monitor

Development uses **PlatformIO + Arduino + M5Unified**.

The first development milestone (`v0.1`) focuses on a flashable launcher plus working offline/on-device utilities, then adds network-backed modules behind a small API layer.

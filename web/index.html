M5Stack StickS3 · 浏览器一键烧录

  1. 使用 USB-C 数据线把 StickS3 接到电脑。
  2. 长按侧面 Reset 约 2 秒；看到内部绿色 LED 闪烁后松开，进入下载模式。
  3. 使用桌面版 Chrome 或 Edge 打开本页。
  4. 点击下面的按钮，选择 StickS3 的串口，然后确认安装。
当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请确认当前页面通过 HTTPS 打开。

安装会写入 Pocket Nexus 固件。首次启动如果尚未保存 Wi-Fi，后续版本会由设备自身提供配置入口，无需把家庭 Wi-Fi 密码提交到 GitHub。

M5Stack StickS3 · 浏览器一键烧录 · v0.5

  1. 使用 USB-C 数据线连接 StickS3。
  2. 需要时长按侧面 Reset 约 2 秒，看到内部绿色 LED 闪烁后松开。
  3. 使用桌面版 Chrome 或 Edge 打开本页。
  4. 点击安装按钮，选择 USB JTAG/serial debug unit。
v0.5 更新
  • 菜单、标题、按钮提示全面改为中文，并使用 M5GFX 中文字库。
  • 修复中文 UTF-8 换行，避免文字被拆坏或截断。
  • 屏保改为构建时生成的 135×240 RGB565 原始图像，不再依赖真机 JPEG 解码。
  • Wi-Fi 支持后台自动重连，每 12 秒恢复一次，不再只在开机时尝试一次。
  • 股票页开始读取现有 stock-alert 的真实行情快照，无需额外 API Key。
  • 语音页加入内置麦克风录音 + 扬声器回放测试，为后续 AI Push-to-Talk 做硬件基础。
升级提示：

如果安装器询问是否擦除设备数据，请选择保留数据，这样已保存的 Wi-Fi 会继续保留。只有彻底重置时才选择 Erase。

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请确认页面通过 HTTPS 打开。

如果设备中没有可用 Wi-Fi 配置，进入“无线网络”后长按侧键 B 可打开临时安全配置热点；连接屏幕显示的 PN-Setup-XXXX 后访问 192.168.4.1。

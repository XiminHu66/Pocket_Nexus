v0.9 更新
  • “一键乐”改成真正的二级菜单：A 下一项、B 打开；进入玩法后 A 触发、B 返回玩法菜单；二级菜单长按 B 返回主菜单。
  • 保留 v0.8 的骰子、抛硬币、今日运势、随机新闻、天气、随机股票、今天吃什么、随机 RSS、30 秒挑战、反应测试和决策轮盘。
  • 参考 Hackster 的 M5Stick 系列项目新增“专注计时”：25 分钟专注 / 5 分钟休息，支持暂停继续和结束蜂鸣。
  • 新增“姿态计时”：利用内置 IMU，倾斜设备选择 5 / 10 / 15 / 25 / 45 分钟，再按 A 开始。
  • 新增“声音仪”：使用内置麦克风测相对 RMS / 峰值声级；显示的是相对声级，不冒充校准过的 dBA。
  • 新增“附近 Wi-Fi”：仅做被动扫描，显示附近网络数量、最强 SSID、RSSI、信道和是否加密，不包含攻击功能。
  • 新增“猜拳”：设备随机出石头 / 剪刀 / 布。
  • 继续保留水平仪校准、RGB565 屏保安全写屏、RSS Orbit、Pocket API、Wi-Fi 自动重连等已有功能。

“一键乐”现在会先进入玩法列表，不再盲切。配置 Wi-Fi / 日程 / 决策轮盘仍然在“设置”第 1 页长按侧键 B；屏保预览在“设置”第 2 页长按 A。

BLE 翻页器 v0.3.0

安装后设备启动为独立的 BLE 翻页器。回到 Pocket Nexus 标签可重新安装原固件。

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请通过 HTTPS 打开本页。

在安装对话框中保持 Erase device 未勾选，以保留原设置和已绑定设备。

在设备上选择模式

同时按住正面 A 和侧面 B 约 1 秒后松开。菜单中 A 切换、B 确认。未设置过模式的设备默认使用 PPT。

  • BOOX · 音量减 / 音量加。在阅读 App 内启用音量键翻页。
  • PPT · Page Down / Page Up。先进入放映。
  • MANGA · 分页用右 / 左方向键，长条漫画可选整屏滚动。
  • VIDEO · 电脑版用下 / 上方向键，手机版可选蓝牙滚轮。手机 App 需支持滚轮输入。

多设备切换 · A+B 按住约 3 秒打开 DEVICES，A 浏览、B 连接。最多记住 4 台，每台保留自己的模式和方向。添加设备时在主机蓝牙列表选择 StickS3 Page。

从旧版刷入时保留设备设置，已配对的设备会出现在第一个位置，可在 Manage devices 中给它加上标签。

  1. 使用 USB-C 数据线连接 StickS3。
  2. 需要时长按侧面 Reset 约 2 秒，看到内部绿色 LED 闪烁后松开。
  3. 使用桌面版 Chrome 或 Edge 打开本页。
  4. 点击安装按钮，选择 USB JTAG/serial debug unit。

升级提示：

从旧版升级时，如果安装器询问是否擦除设备数据，请选择保留数据，以继续使用已保存的 Wi-Fi。只有异常或彻底重置时才选择 Erase。

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请确认当前页面通过 HTTPS 打开。

首次启动且没有已保存 Wi-Fi 时，StickS3 会显示临时 PN-Setup-XXXX 热点和随机 WPA2 密码。连接后访问 192.168.4.1。

Pocket Nexus

M5Stack StickS3 · 浏览器一键烧录 · v0.9

  1. 使用 USB-C 数据线连接 StickS3。
  2. 需要时长按侧面 Reset 约 2 秒，看到内部绿色 LED 闪烁后松开。
  3. 使用桌面版 Chrome 或 Edge 打开本页。
  4. 点击安装按钮，选择 USB JTAG/serial debug unit。
v0.9 更新
  • “一键乐”改成真正的二级菜单：A 下一项、B 打开；进入玩法后 A 触发、B 返回玩法菜单；二级菜单长按 B 返回主菜单。
  • 保留 v0.8 的骰子、抛硬币、今日运势、随机新闻、天气、随机股票、今天吃什么、随机 RSS、30 秒挑战、反应测试和决策轮盘。
  • 参考 Hackster 的 M5Stick 系列项目新增“专注计时”：25 分钟专注 / 5 分钟休息，支持暂停继续和结束蜂鸣。
  • 新增“姿态计时”：利用内置 IMU，倾斜设备选择 5 / 10 / 15 / 25 / 45 分钟，再按 A 开始。
  • 新增“声音仪”：使用内置麦克风测相对 RMS / 峰值声级；显示的是相对声级，不冒充校准过的 dBA。
  • 新增“附近 Wi-Fi”：仅做被动扫描，显示附近网络数量、最强 SSID、RSSI、信道和是否加密，不包含攻击功能。
  • 新增“猜拳”：设备随机出石头 / 剪刀 / 布。
  • 继续保留水平仪校准、RGB565 屏保安全写屏、RSS Orbit、Pocket API、Wi-Fi 自动重连等已有功能。
升级提示：

建议选择保留数据 / 不 Erase，这样已保存的 Wi-Fi、事件、决策轮盘候选项和水平仪校准数据会继续保留。

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请确认页面通过 HTTPS 打开。

“一键乐”现在会先进入玩法列表，不再盲切。配置 Wi-Fi / 日程 / 决策轮盘仍然在“设置”第 1 页长按侧键 B；屏保预览在“设置”第 2 页长按 A。

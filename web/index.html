  1. 使用 USB-C 数据线连接 StickS3。
  2. 需要时长按侧面 Reset 约 2 秒，看到内部绿色 LED 闪烁后松开。
  3. 使用桌面版 Chrome 或 Edge 打开本页。

v0.7 更新
  • 水平仪改为“姿态校准”模式：把设备摆成你认为的水平姿态，按 A 一次即可设为零点；以后横放、竖放或侧放都以这个姿态为基准。
  • 屏保不再直接推送 RGB565 缓冲区，而是逐像素按颜色值写屏，绕开 StickS3/M5GFX 的字节序显示异常。
  • 菜单从 14 个入口精简为 9 个：信息台、市场资讯、一键乐、日程倒数、语音助手、红外工具、水平仪、倾斜游戏、设置。
  • “信息台”合并首页 + 桌面信息 + 时钟；“市场资讯”合并股票 + 新闻；“日程倒数”合并日程 + 倒计时；“设置”合并 Wi-Fi + 屏保。
  • 新增“一键乐”：骰子、抛硬币、今日运势、随机新闻、刷新天气、随机股票、帮我决定。短按 A 触发，长按 A 切换玩法。
  • 新增轻量天气接口，无需 API Key；通过 Pocket Nexus Worker 获取城市级网络位置，再从 Open-Meteo 拉取温度、体感、湿度和风速。
升级提示：

建议选择保留数据 / 不 Erase，这样 Wi-Fi、事件和水平仪校准数据都能保留。升级后第一次用水平仪时，把设备按你常用姿态放稳，再按一次 A 校准。

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请确认页面通过 HTTPS 打开。

重新配置 Wi-Fi / 日程：进入“设置”第 1 页，长按侧键 B，连接屏幕显示的 PN-Setup-XXXX，再访问 192.168.4.1。屏保预览在“设置”第 2 页长按 A。

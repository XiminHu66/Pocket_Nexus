Pocket Nexus

M5Stack StickS3 · 浏览器一键烧录 · v0.8

  1. 使用 USB-C 数据线连接 StickS3。
  2. 需要时长按侧面 Reset 约 2 秒，看到内部绿色 LED 闪烁后松开。
  3. 使用桌面版 Chrome 或 Edge 打开本页。
  4. 点击安装按钮，选择 USB JTAG/serial debug unit。
v0.8 更新
  • “一键乐”扩展到 11 个玩法，同时保留骰子、抛硬币、今日运势、随机新闻、刷新天气和随机股票。
  • 新增“今天吃什么”：内置中式 / 亚洲口味和简单家常选项，本地随机，不联网也能用。
  • 新增“随机 RSS”：直接读取 RSS Orbit 的 Cloudflare KV 实时缓存，通过 Pocket API 与 RSS Orbit Worker 的 Service Binding 获取内容。
  • 新增“30秒挑战”：随机生成一个小运动 / 活动挑战，屏幕实时倒数 30 秒，结束时蜂鸣提示。
  • 新增“反应测试”：随机等待后出现“按！”，再次按 A 显示毫秒反应时间；抢跑会提示重新开始。
  • 新增“决策轮盘”：候选项不写死，可在安全配置页自行填写，用 | 分隔，例如 日料|中餐|在家做饭。
  • 继续保留 v0.7 的水平仪姿态校准、逐像素屏保写屏、精简菜单和 Wi-Fi 后台重连。
升级提示：

建议选择保留数据 / 不 Erase，这样已保存的 Wi-Fi、事件和水平仪校准数据会继续保留。决策轮盘首次使用会有默认候选项，之后可自行修改。

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge。 浏览器阻止了串口访问，请确认页面通过 HTTPS 打开。

配置 Wi-Fi / 日程 / 决策轮盘：进入“设置”第 1 页，长按侧键 B，连接屏幕显示的 PN-Setup-XXXX，再访问 192.168.4.1。屏保预览仍在“设置”第 2 页长按 A。
